1. **Асинхронность:** Все запросы теперь асинхронные, что позволяет:

   - Добавить задержки для тестирования UX
   - Обрабатывать состояния загрузки

2. **Единообразие:** Все компоненты используют единый API слой из `shared/api/`

3. **Обработка ошибок:** Добавлена базовая обработка ошибок с логированием

4. **UX улучшения:** Добавлены индикаторы загрузки для лучшего пользовательского опыта
